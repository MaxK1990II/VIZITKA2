# Аналитика портфолио

Подключение Яндекс Метрики подготовлено, но **счётчик не задан и сбор данных не включён**. Без корректного `NEXT_PUBLIC_YANDEX_METRIKA_ID` сайт не создаёт очередь Метрики, не загружает её скрипт и не устанавливает обработчики аналитики. Тестовые номера используются только в тестах.

## Включение

1. Создать счётчик для `kanochkinmm.ru` в своём аккаунте Яндекс Метрики. Не включать Вебвизор, запись форм, автоматические цели и отслеживание ссылок; в коде сайта запись сессии, карта кликов и автоматическое отслеживание ссылок отключены.
2. Указать настоящий числовой ID в переменной окружения сборки `NEXT_PUBLIC_YANDEX_METRIKA_ID`. Это публичный номер счётчика, не токен доступа. В локальной разработке можно использовать `.env.local` (файл исключён из Git).
3. Создать цели типа «Целевое событие» с идентификаторами из таблицы ниже.
4. Выполнить новую сборку и публикацию. Переменные `NEXT_PUBLIC_*` встраиваются в JavaScript при сборке; изменение окружения уже собранного статического сайта не включает счётчик.
5. Проверить реальные визиты и цели в интерфейсе Метрики. Локальные тесты проверяют вызовы API и жизненный цикл, **но не подтверждают доставку данных в сервис**. Блокировщик или настройки приватности браузера могут отключить сбор.

Чтобы выключить сбор, удалить значение переменной, пересобрать и опубликовать сайт.

## События

| Идентификатор цели | Что означает | Дополнительный параметр |
| --- | --- | --- |
| `profile_open` | Показан профиль после вступления или перехода по прямой ссылке | — |
| `demo_view` | Не менее 15% блока демонстрации попало в видимую область профиля | — |
| `demo_launch` | Нажата кнопка запуска демонстрации | — |
| `contact_click` | Выбран контактный канал | `channel`: `telegram`, `email`, `github`, `vk`, `max`, `wechat` |
| `contact_save` | Нажата кнопка сохранения контакта | — |
| `profile_pdf` | Нажата ссылка скачивания профиля в PDF | — |
| `press_open` | Открыта публикация о проекте | — |
| `project_source` | Выбран внешний источник проекта | — |
| `navigation_click` | Выбран раздел в навигации профиля | — |
| `scroll_depth` | Нижняя граница видимой области достигла доли высоты профиля | `threshold`: `25`, `50`, `75`, `100` |

Во всех целях есть `locale` и `event`. Другие параметры отбрасываются. Цель клика означает намерение: она не подтверждает отправку сообщения или завершённое скачивание файла. `demo_view` означает видимость блока, а `demo_launch` — запуск. Действия внутри HTML-симуляции не собираются.

`profile_open`, `demo_view` и каждый порог глубины учитываются один раз на просмотр страницы, в том числе при повторном монтировании React StrictMode. Осознанные повторные клики учитываются отдельно. Переключение языка или возврат на страницу после перехода в раздел прессы создаёт новый просмотр; переходы по якорям и возврат из вступления в профиль не создают его. Для этого Bootstrap хранит идентификатор экземпляра страницы, который не отправляется в Метрику. Глубина измеряется у `.bento-stage`, где действительно прокручивается профиль, а не у окна браузера. Если содержимое целиком помещается на экран, видимость всей страницы считается 100% и без прокрутки.

`AnalyticsBootstrap` монтируется перед вступлением и создаёт просмотр. `PortfolioAnalytics` монтируется вместе с профилем и отслеживает действия. Для новых кнопок используются `data-analytics-event` и, для контактов, `data-analytics-channel`; URL и текст элемента не считываются.

## Ограничения данных

Реализация передаёт в событии только перечисленные параметры. Для просмотра задаётся канонический путь локали (`/`, `/en/` и т. д.) без query-параметров и якоря, фиксированный заголовок и пустой реферер. Клики по ссылкам не передают полный адрес назначения. Нет пользовательских идентификаторов, значений форм и содержимого диалогов. Вебвизор, запись дочерних iframe, карта кликов, автоматические внешние ссылки, отслеживание хеша, ecommerce и Яндекс Тег Менеджер выключены. Сам сервис Метрики после включения обрабатывает стандартные технические данные браузера по своим настройкам; этот список описывает именно параметры, добавленные приложением.

При `Do Not Track: 1` или `Global Privacy Control` подключение пропускается. Если библиотека заблокирована, интерфейс сайта продолжает работать. В текущем выпуске без ID не возникает запросов к Метрике и всплывающих окон для посетителя.

## Как использовать отчёты

Сравнивать просмотры страницы с `profile_open`, затем `demo_view`, `demo_launch` и `contact_click`. Разбивка по `locale` помогает увидеть различия между языковыми версиями; `channel` — востребованные способы связи. Пороги `scroll_depth` показывают, до какой части профиля доходят. Пока счётчик не создан и не активирован новой сборкой, этих данных нет.
